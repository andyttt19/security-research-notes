# Research Environment

## Laboratory Setup

The research is performed in a controlled local environment.

## Environment Components

- Local virtual machines
- Test applications
- Open-source software
- Self-created test files

## Research Principles

- Only authorized software and data are used.
- Testing is performed for educational and defensive purposes.
- Findings are documented to improve understanding of software security.

## Focus Areas

- Parser security
- Vulnerability analysis
- Debugging methodology
- Regression testing
